# TP1_Unity_TECMUL_G16

Nome: Diogo de Carvalho Carteado Alves

Versão Unity: 6000.3.9f1

Resumo do Jogo:

O desenvolvimento do jogo começou pela criação do cenário. Para isso, foram utilizados assets da store, com os quais foi construído um quarto que serve como ambiente principal do jogo. Após a definição do espaço, foram implementadas as funcionalidades através de vários scripts.

Foram desenvolvidos scripts para permitir a interação com o ambiente, incluindo a abertura de gavetas e portas, bem como a capacidade de o jogador pegar em objetos. Além disso, foi criado um sistema de movimentação do player, garantindo controlo fluido dentro do cenário.

Ao nível da lógica do jogo, foi implementado um script responsável pelas condições de vitória e derrota, definindo assim o objetivo e o desafio para o jogador. Por fim, foi também criado um sistema de recolha de troféus, que contribui para a progressão e conclusão do jogo.
          
          

Como jogar:

          -Usar WASD para movimento do player
          
          -Usar o E para interagir com objetos/portas/gavetas
          
          -Usar o rato para movimentar a câmera

          -Objetivo: Encontrar os 5 troféus para conseguir abrir a porta principal e escapar do quarto

Como abrir o projeto:

          -O projeto tem 2 scenes: SampleScene é o jogo e o MenuPrincipal é o primeiro menu que aparece ao iniciar o jogo
          
          -Para abrir o projeto apenas abrir a pasta do projeto e se iniciar pela SampleScene vai direto para o jogo, se iniciar pelo MenuPrincipal scene começa no menú principal
